# 构建说明

以下命令均在 Windows PowerShell 中执行，用于构建 Cloud、Agent、Detector Demo 和 setUp。

## 1. 进入项目根目录

```powershell
Set-Location 'D:\codes\free-sun\anxinyun3.0\allTrunk\codes\services\AiHandler\FirmwareUpgrade'
```

## 2. 创建输出目录

```powershell
New-Item -ItemType Directory -Force '.\bin\test' | Out-Null
```

## 3. 构建 Cloud

构建前先停止正在运行的 `cloud.exe`，否则 Windows 可能不允许覆盖文件。

```powershell
go build -buildvcs=false -trimpath -o '.\bin\test\cloud.exe' ./cmd/cloud
```

Cloud 管理页面通过 `go:embed` 编译进可执行文件。修改 `cmd/cloud/web` 后必须重新构建并重启 Cloud。

## 4. 构建 Agent Windows 版本

构建前先停止正在运行的 `agent.exe`。

```powershell
go build -buildvcs=false -trimpath -o '.\bin\test\agent.exe' ./cmd/agent
```

## 5. 构建 Agent Linux ARM64 版本

```powershell
$env:CGO_ENABLED = '0'
$env:GOOS = 'linux'
$env:GOARCH = 'arm64'
go build -buildvcs=false -trimpath -o '.\bin\test\agent-linux-arm64' ./cmd/agent
$linuxBuildExitCode = $LASTEXITCODE
Remove-Item Env:CGO_ENABLED, Env:GOOS, Env:GOARCH
if ($linuxBuildExitCode -ne 0) { exit $linuxBuildExitCode }
```

如果目标 Linux 设备是 x86-64 架构，将 `GOARCH` 改为 `amd64`，并建议将产物名改为 `agent-linux-amd64`。

## 6. 构建 Detector Demo

构建前先停止正在运行的 `detector-demo.exe`。

```powershell
go build -buildvcs=false -trimpath -o '.\bin\test\detector-demo.exe' ./cmd/detector-demo
```

Detector Demo 使用的 `cmd/detector-demo/img/通道图` 会通过 `go:embed` 编译进可执行文件，不需要复制到 `bin/test`。

## 7. 构建 setUp

构建前先停止正在运行的 `setup.exe`。

```powershell
go build -buildvcs=false -trimpath -o '.\bin\test\setup.exe' ./cmd/setup
```

## 8. 连续构建全部程序

```powershell
go build -buildvcs=false -trimpath -o '.\bin\test\cloud.exe' ./cmd/cloud
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }

go build -buildvcs=false -trimpath -o '.\bin\test\agent.exe' ./cmd/agent
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }

go build -buildvcs=false -trimpath -o '.\bin\test\detector-demo.exe' ./cmd/detector-demo
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }

go build -buildvcs=false -trimpath -o '.\bin\test\setup.exe' ./cmd/setup
if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }

$env:CGO_ENABLED = '0'
$env:GOOS = 'linux'
$env:GOARCH = 'arm64'
go build -buildvcs=false -trimpath -o '.\bin\test\agent-linux-arm64' ./cmd/agent
$linuxBuildExitCode = $LASTEXITCODE
Remove-Item Env:CGO_ENABLED, Env:GOOS, Env:GOARCH
if ($linuxBuildExitCode -ne 0) { exit $linuxBuildExitCode }
```

构建结果：

```text
bin/test/
├── cloud.exe
├── agent.exe
├── detector-demo.exe
├── setup.exe
└── agent-linux-arm64
```

## 9. 构建前验证（可选）

```powershell
go test ./cmd/cloud ./cmd/agent ./cmd/detector-demo ./cmd/setup
```

如果只修改了某个程序，可以只测试并构建对应的 `./cmd/...` 包。
