# 远程终端连接诊断

2026-10-12 17:18（北京时间），对 `https://dvcplttest.anxinyun.cn/terminal/connect?device_id=diagnostic-unregistered` 发送无凭据 WebSocket Upgrade 探测，返回 HTTP 200、`Content-Type: text/html`、927 字节，未升级到 WebSocket。这说明该域名的终端路径没有进入设备 Node 终端网关；Agent 没有 terminal.open 日志符合这个现象。

部署修复：将 `/terminal/connect` 原路径直接转发到设备 Node API Service（与 Web `/_api` 对应的设备后端相同），支持 WebSocket Upgrade，禁止落到 React 页面、POMS 服务或普通 koa-proxy。参考 `node-agent-ingress.example.yaml`，须替换实际 namespace、Service 和端口后合并现有入口配置。此次没有修改线上入口。

新版 Node 日志依次包含 upgrade_received、browser_connected、authenticated、terminal_open_sent、agent_opened 和 closed 原因；带设备及随机会话标识，不记录凭据或终端输入。建记录失败另输出经过脱敏的数据库阶段和错误码。若完全没有 upgrade_received，应先检查入口路由和 Node 发布版本。

验收须使用真实已登录用户及在线 Agent：终端握手为 101，Node 出现 terminal_open_sent 与 agent_opened，Agent 出现 terminal open，页面可执行命令。无凭据探测仅用于路由检查，不能证明真实会话成功。
