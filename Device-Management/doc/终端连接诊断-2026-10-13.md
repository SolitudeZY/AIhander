# K8s 远程会话连接诊断

## 现象与证据

设备在线，HTTP `/_api/edgeAgent/devices/.../remote-sessions` 返回 200、空列表，但浏览器终端连接失败。会话列表读取数据库，终端另外使用 WebSocket，二者入口不同。2026-10-13 从开发电脑发送无凭据 WebSocket Upgrade 请求，使用未注册的诊断设备 ID，不打开真实板端 shell：

| 入口 | 返回 | 判断 |
| --- | --- | --- |
| 网页域名 `https://dvcplttest.anxinyun.cn/terminal/connect` | 200、text/html、React 页面 | 请求落到网页，没有 WebSocket Upgrade |
| 设备 API `https://dvcpltapitest.anxinyun.cn/terminal/connect` | 101 | 设备终端入口可以升级 |
| 设备 API `/terminal/connect`，Origin 为网页域名 | 101 | 当前入口接受该跨域握手 |
| 设备 API `/api/v1/agents/connect` | 401 | 请求进入 Agent 网关，无设备凭据拒绝符合预期 |

已有前端在 HTTPS 下强制选择网页 origin，依赖同源 Ingress 的 `/terminal/connect` 路由；当前环境该路由缺失，导致本地 HTTP 正常而测试 HTTPS 失败。101 仅证明连接升级，后续仍需平台用户鉴权及 Agent 打开终端，不能据此宣称真实会话成功。

## 代码与部署

新增 Web 运行时 `EDGE_AGENT_API_URL`（或 `--edgeAgentApiUrl`），由 Web `/api/root` 返回 `edgeAgentApiUrl`。React 终端优先使用该设备 API 根地址，未配置保持原本本地/同源行为。配置验证限制 HTTP/HTTPS，禁止凭据、查询串、片段以及 HTTPS 网页使用 HTTP；终端仍在首条 WebSocket 消息传当前用户登录 token，不把凭据放入 URL。

1. 开发侧提交本轮明确的 Web 源码、测试及文档，从对应 SVN revision 重建 Web 镜像。保留现有 Node 12 production 运行、Node 22 前端编译配置。
2. 测试侧更新 Web Deployment 镜像，在 Web 容器环境变量设置 `EDGE_AGENT_API_URL=https://dvcpltapitest.anxinyun.cn`，等待滚动发布结束。只在 API Pod 设置变量不会影响网页。
3. 刷新页面，检查网页 `/api/root` 的 `edgeAgentApiUrl` 为设备 API 地址。只核对这一个字段，不传播完整响应中的其他配置或凭据。
4. 使用已登录账号和在线设备新建远程会话，Network 选择 WS；应连接 `wss://dvcpltapitest.anxinyun.cn/terminal/connect?...`、返回 101，再收到设备打开确认和输出。用 `uname -a` 等只读命令确认交互，结束会话并检查记录。
5. 若还是指向网页域名，核对新版镜像、Web 容器环境和 `/api/root`；若已到 API 但握手失败，检查设备 API 的 Ingress Upgrade/长连接支持；若出现鉴权或设备离线错误，查看对应 Node 日志。API 当前使用内存 Agent 连接池，多实例时终端必须能找到持有该 Agent 连接的实例；不能以随机分流解决。

本次没有新 SQL，也不修改已在线板端的 server_url、token 或状态文件。不需新增 Jenkins/Docker 构建参数，环境变量在服务启动时读取。已有部署可选择另一种修复：将网页域名 `/terminal/connect` 原路径直接路由到设备 Node Service，参考 `node-agent-ingress.example.yaml` 替换实际参数后合并；无需同时采用两种方案。

## 验证范围

Web 全部 25 项回归通过；Node 12.22.12 真实 production scaffold 启动和 `/api/root` 配置透传通过。实际生产 webpack 编译成功，3 项警告为既有包体积/性能建议。Browser 插件不可用，采用已有 Playwright/Chrome 对生产 React 页面进行模拟 HTTP/WebSocket 验证，覆盖配置前后连接地址、首帧鉴权、URL 无 token、终端输出和结束会话按钮，无页面脚本异常。

浏览器模拟验收与测试域名实时无凭据探测分别进行，不连接真实终端、不使用真实用户 token。本轮未执行 SVN commit、修改集群路由、发布镜像或执行数据库操作；核对时测试文件已由其他操作纳入 r244，剩余源码提交目标见发布交接文档。K8s 与板端完整验收由测试同事在部署后执行。
