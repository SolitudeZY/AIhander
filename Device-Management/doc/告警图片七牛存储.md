# 告警图片七牛存储

## 整理与实施方案

告警元数据在 PostgreSQL，但原图在 Node 容器本地目录。容器替换后，数据库仍显示“已上传”，图片接口返回“证据文件缺失”。改为复用现有七牛适配器：图片上传七牛后保存对象定位信息；图片接口鉴权后按需生成下载签名。现有页面继续使用同一个图片接口。

## 新告警

部署新版 Node 并设置 `EDGE_AGENT_FILE_STORAGE=qiniu`，复用模型文件的七牛配置：

```text
ANXINCLOUD_QINIU_ACCESSKEY
ANXINCLOUD_QINIU_SECRETKEY
ANXINCLOUD_QINIU_BUCKET_RESOURCE
ANXINCLOUD_QINIU_DOMAIN_QNDMN_RESOURCE
EDGE_AGENT_QINIU_DOWNLOAD_TTL_SECONDS=7200
```

图片以 JPEG/PNG 上传到 `edge-agent/alarms/<随机ID>.<扩展名>`。`edge_agent_record.data.image_storage` 保存 `storage`、`bucket`、`object_key` 和不含签名的 `object_url`；不保存会过期的下载链接。无需数据库迁移。

同一事件的入库和迁移用事务及事件锁串行处理。七牛和数据库均成功才给 Agent 上报确认；七牛失败不落成功记录、不确认，Agent 会重试。数据库保存失败清理本次七牛对象。已存七牛的重复事件不重复上传。

历史图片接口在平台用户鉴权后生成新签名并返回 302，Web 现有代理会跟随重定向返回图片。Pod 更换后只要数据库和七牛配置相同即可读取，不依赖容器图片目录。七牛 bucket 或域名改变需同时处理历史对象；不要将旧对象当作临时文件设置自动清理策略。

`EDGE_AGENT_FILE_STORAGE=local` 仍用于显式本地测试，图片存本地。旧记录也仍走原本的本地读取，所以迁移前需保留旧目录。

## 旧图迁移及板子原图恢复

在 API 目录执行，提供目标环境的私有配置文件，或直接设置环境变量。环境变量优先于文件中的值。默认仅检查，不上传或改数据库；输出每条事件状态以及汇总。`missing_file` 不会被标记为已迁移。工具保留旧源文件，重复执行跳过已迁移事件。

检查旧 Node 图片目录：

```bash
node migrate-agent-evidence.js --env-file /secure/node.env --source-dir /old-data/edge-agent/alarms --device ee:4d:fe:90:97:3d
```

确认指向正确数据库与 bucket 后迁移，增加 `--apply`：

```bash
node migrate-agent-evidence.js --env-file /secure/node.env --source-dir /old-data/edge-agent/alarms --device ee:4d:fe:90:97:3d --apply
```

如果旧容器文件丢失，先从板子导出对应原图，再定向恢复。此前已验证事件 93 原图仍在板子：

```bash
scp kickpi@10.8.30.54:/home/kickpi/testAgent/db/alarm-images/2026/10/12/1910417329.jpg ./event-93.jpg
node migrate-agent-evidence.js --env-file /secure/node.env --device ee:4d:fe:90:97:3d --row 93 --image-file ./event-93.jpg
node migrate-agent-evidence.js --env-file /secure/node.env --device ee:4d:fe:90:97:3d --row 93 --image-file ./event-93.jpg --apply
```

事件 92 原图路径为 `/home/kickpi/testAgent/db/alarm-images/2026/10/12/1731584374.jpg`。实际路径应按板子 `alarm_records.image_path` 核对。工具不改板子数据库的上报状态，也不重新创建告警；只更新已有事件图片定位信息，保留发生时间、接收时间等历史元数据。

## 验收

1. 新告警写入 `image_storage.storage=qiniu`，七牛对象可下载。
2. 删除测试 Pod 的本地图片目录或替换 Pod 后，历史图片仍显示。
3. 上传/入库失败时未发送 `alarmReportResult`，重试后只保留一条事件。
4. 旧记录迁移前兼容本地读取，迁移后七牛读取；文件缺失明确输出并使用板子原图恢复。

七牛解决图片持久化；Agent 控制 WebSocket 的多实例会话路由仍需要独立处理。
